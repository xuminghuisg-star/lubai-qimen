# 渌白奇门 — lubai-qimen

通用奇门遁甲助手，适用于 Claude Code。

## 安装方法

将 `lubai-qimen skill.zip` 下载后解压到 `.claude/skills/lubai-qimen/` 目录：

```bash
unzip lubai-qimen skill.zip -d ~/.claude/skills/lubai-qimen/
```

或在 Claude Code 中直接使用 `/lubai-qimen` 触发。

## 内容

- 取用神大全（婚姻、官讼、考试、疾病、出行、求财等全事件）
- 格局详解（门迫、入墓、空亡、击刑）
- 符号含义（九星、八门、八神、天干、地支）
- 古籍原文（御定奇门宝鉴、奇门遁甲秘笈大全）
- 通用分析逻辑（六大步骤+分类断局思路）

## 来源

参考《御定奇门宝鉴》（清代康熙钦定）与《奇门遁甲秘笈大全》（明·刘伯温）原典整理。
